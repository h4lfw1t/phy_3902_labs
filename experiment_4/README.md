# PHY 3902 Experiment 4: PID Control and Feedback Voltage

## Overview
This experiment explores the principles and practical implementation of Proportional-Integral-Derivative (PID) control systems. You will follow a series of stages to understand, build, and analyze a PID-controlled system, focusing on feedback voltage regulation.

## Objectives
- Understand the theory behind PID controllers and their role in feedback systems.
- Implement and tune a PID controller for a physical system.
- Analyze system response to different PID parameter settings.
- Observe the effects of proportional, integral, and derivative terms individually and in combination.

## Experiment Stages

### 1. Introduction to PID Control
- Review the basic concepts of feedback and PID control as described in the provided documentation.
- Familiarize yourself with the experimental setup and required hardware/software.

### 2. Open-Loop System Characterization
- Measure and record the system's response without feedback (open-loop).
- Analyze the system's natural behavior and limitations.

### 3. Proportional Control (P)
- Implement proportional-only control.
- Observe and record the system's response to setpoint changes.
- Note steady-state error and response speed.

### 4. Proportional-Integral Control (PI)
- Add the integral term to the controller.
- Study the effect on steady-state error and system stability.
- Tune the integral gain and document observations.

### 5. Proportional-Derivative Control (PD)
- Add the derivative term to the controller.
- Observe the effect on overshoot and response time.
- Tune the derivative gain and document observations.

### 6. Full PID Control
- Combine all three terms (P, I, D) in the controller.
- Systematically tune each parameter to achieve optimal performance.
- Record the system's response and compare with previous stages.

### 7. Analysis and Discussion
- Analyze the collected data for each control mode.
- Discuss the advantages and trade-offs of each PID term.
- Summarize findings and relate them to theoretical expectations.

## Data and Reporting
